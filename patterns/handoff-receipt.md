# Handoff Receipt Template

A small, tool-agnostic template for transferring work between agents or people.

## Fields
- TASK_ID
- INPUT_VERSION
- OUTPUT_VERSION
- CHANGED
- PRESERVE
- VERIFIED
- SKIPPED_CHECKS
- EXPECTED_ITEMS
- CHECKED_ITEMS
- SKIPPED_ITEMS
- COVERAGE_STATUS
- NEXT_AGENT

All example values should be synthetic. Do not place secrets or confidential project data in public receipts.
